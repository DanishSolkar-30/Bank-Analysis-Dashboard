# 📊 Customer Churn Analysis Dashboard (Microsoft Excel)

## 📌 Project Overview

The **Customer Churn Analysis Dashboard** is an interactive Microsoft Excel project designed to analyze customer behavior and identify churn patterns. The dashboard transforms raw customer data into meaningful business insights using Excel's powerful data analysis and visualization features.

This project helps businesses understand customer retention trends, identify high-risk customer segments, and make data-driven decisions to improve customer loyalty.

---

## 🎯 Objectives

* Analyze customer churn data effectively.
* Calculate key performance indicators (KPIs).
* Identify customer segments with higher churn rates.
* Create an interactive dashboard for business decision-making.
* Improve data visualization and reporting skills using Microsoft Excel.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel (2019 or later / Microsoft 365 recommended).
3. Navigate to the Dashboard worksheet.
4. Use the slicers to filter data dynamically.
5. Analyze KPIs, charts, and customer insights.
